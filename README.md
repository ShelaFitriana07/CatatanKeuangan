# CatatanKeuangan
CatatanKeuangan adalah aplikasi web yang digunakan untuk mengelola keuangan secara sederhana. Aplikasi ini memungkinkan admin untuk mencatat pemasukan dan pengeluaran, melihat saldo akhir, serta mengelola pengguna. Pengguna biasa hanya dapat melihat data keuangan tanpa hak untuk mengubahnya.
